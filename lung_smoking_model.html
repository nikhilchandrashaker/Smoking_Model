How this is modeled

The darkening is not linear. Each cigarette deposits a small, largely permanent residue of tar and particulate that macrophages carry to lymph tissue but can't fully clear — so it accumulates. Alveolar macrophages laden with this material are literally black under a microscope, which is why smokers' lungs read as progressively sootier rather than uniformly grey.

The curve here uses a saturating exponential (fast visible change in the first ~10 pack-years, flattening after), consistent with how tar staining is described in gross pathology and autopsy literature — this is an illustrative approximation, not a diagnostic tool.
